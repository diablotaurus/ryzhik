# Рыжик и маяк

Пиксельный платформер про лисёнка Рыжика: зажечь маяк в долине и вернуться домой через ночной лес.

**Играть:** https://diablotaurus.github.io/ryzhik/ — обновляется автоматически после каждого push в `main` (GitHub Actions → `.github/workflows/pages.yml`).

## Как запустить

- Просто открыть `src/index.html` в браузере (работает и с `file://`).
- Или с локальным сервером: `python -m http.server 8737 --directory src` → http://localhost:8737

## Сборка в один файл

```
node tools/build.js
```

Получится `dist/ryzhik.html` — всё (стили, скрипты, уровни) внутри одного файла, удобно отправить или опубликовать.

## Структура

```
src/
  index.html      разметка: канвас, меню, тач-кнопки
  style.css       оформление страницы
  js/levels.js    уровни — ASCII-карты (легенда символов в начале файла)
  js/audio.js     звуки (Web Audio, без файлов)
  js/input.js     клавиатура и тач-кнопки
  js/game.js      состояние, загрузка уровня, физика, правила
  js/render.js    отрисовка мира и HUD
  js/main.js      экраны меню/победы/проигрыша, игровой цикл, масштабирование
tools/build.js    сборка в dist/ryzhik.html
html/             исходные прототипы v0.0.1–v0.0.6
screenshots/      скриншоты прототипа
```

Скрипты обычные (не ES-модули) и подключаются по порядку — так игра открывается двойным кликом без сервера.

## Как сделать уровень

Добавить объект в массив `LEVELS` в `src/js/levels.js`: 15 строк одинаковой длины, символы — по легенде в начале файла. Обязательно поставить `@` (старт) и `!` (цель).
